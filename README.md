# 架空のアウトドアサウナ運営企業「KOHAN SAUNA」のコーポレートサイト

もともとは架空の建設会社のコーポレートサイトを、Photoshop のデザインカンプから静的コーディングしたものです。その後、テキストや画像を差し替えるなどしてアレンジを加え、半オリジナルのWEBサイトに仕上げています。


## コンセプト
「サウナ × 大自然」をテーマにしています。
どちらも高いリラックス効果があり、組み合わせることで現代のストレス社会に生きる人々に、より深い癒しを提供できると考えました。
私自身サウナが大好きで、「こんなサウナがあったら絶対に行ってみたい！」という理想をイメージしながら制作しました。


## ページ構成
トップページ1枚のみ


## デザインカンプ
`Photoshop`


## 使用した技術
- HTML/CSS/JavaScript
- Sass（Dart Sass）
- CSS設計（BEM/FLOCSS）


## 実装した機能およびUIパーツ
- ハンバーガーメニュー
- ローディング画面
- スクロールスパイ（スクロール位置に応じてナビゲーションをハイライト）
- スムーススクロール
- ページの先頭に戻るボタン
- フェードスライダー（slickを使用）
